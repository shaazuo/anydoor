# 任意门 AnyDoor

> 把任意内网 Web 界面，一键变成飞牛桌面上的独立小窗应用。

![版本](https://img.shields.io/badge/version-0.0.2-blue)
![平台](https://img.shields.io/badge/platform-fnOS%20x86__64-green)
![许可](https://img.shields.io/badge/license-MIT-lightgrey)

## 这是什么

在飞牛（fnOS）上，如果你想把**光猫、路由器、群晖、ESXi、交换机、OA、监控**这类内网 Web 后台，直接变成飞牛桌面上的一个个独立图标、点开就是小窗，而不是每次都去记 IP 和端口——任意门就是干这个的。

它最像的是飞牛自带的「WatchCow」（监视 + 快捷方式），但任意门是它的「Plus 版」：

| | WatchCow | 任意门 |
|---|---|---|
| 打开内网站点 | 图标跳转 | ✅ 桌面独立小窗 |
| 每个站点独立端口 | — | ✅ 自动分配、冲突自避让 |
| 公网访问 | 需自行配置 | ✅ 自动写外网地址 |
| 图标 | 固定 | ✅ 自动抓 / 预置 / 文字 / 上传 |
| 站点管理界面 | 简单 | ✅ 图形化管理 + 健康探测 |

## 功能特性

- **一键添加站点**：填个 IP 和端口，自动生成桌面空壳应用图标
- **端口智能分配**：按目标端口自动映射（80→53080、443→53443），冲突自动 +1，可手动改
- **公网访问**：自动对接飞牛 Connect，给每个站点写独立子域名外网地址
- **透明反向代理**：支持 HTTP/HTTPS、WebSocket、子路径（如 `/dist`）、302 跟随、Cookie 本地化
- **四种图标**：自动抓 favicon、8 个预置图形、单文字图标（自选底色）、手动上传 PNG
- **健康探测**：周期性探测每个站点可达性，状态一目了然
- **临时通道**：临时地址快速打开，不生成桌面图标
- **响应式管理页**：对齐飞牛原生 Semi Design 风格，小窗/大屏自适应

## 安装

### 方式一：从 Release 安装

1. 到 [Releases](../../releases) 下载最新的 `.fpk` 文件
2. 飞牛「应用中心」→「手动安装」→ 选择该 fpk

### 方式二：从源码构建

```bash
# 需要飞牛开发者工具 fnpack
fnpack create   # 初始化工程
fnpack build    # 打包成 .fpk
appcenter-cli install-fpk anydoor-0.0.2.fpk -v 1
```

## 使用

1. 安装后，在飞牛桌面打开「任意门」
2. 管理页 `http://<飞牛IP>:8999`（默认端口）
3. 点「添加站点」，填名称 + 目标地址（可带端口/协议/子路径）
4. 保存后，桌面会出现对应的空壳应用图标，点开即用

## 目录结构

```
anydoor/
├── manifest            # 应用清单（上架用）
├── ICON.PNG            # 64x64 图标（社区商店规范命名）
├── ICON_256.PNG        # 256x256 高清图标
├── server/
│   └── core.py         # 核心服务：管理端 + 透明转发器 + 应用生成
├── tpl/                # 空壳应用模板（生成各站点桌面图标用）
│   ├── cmd/            # 生命周期脚本
│   └── config/         # 权限/资源声明
├── config/             # 应用本体配置
└── ui/                 # 桌面入口与图标资源
```

## 工作原理

任意门是一个常驻服务，它做三件事：

1. **管理端**（`:8999`）：图形化管理站点、图标、临时通道
2. **透明转发器**：为每个站点在本地分配一个独立端口，反向代理到目标内网地址
3. **空壳应用生成**：用 `tpl/` 模板，为每个站点打包成一个飞牛桌面应用图标

之所以能给每个站点分配独立端口 + 独立子域名，是因为飞牛给每个应用入口都分配了独立源（`<appname>-web.<用户域>`），站点因此看到的是自己的根路径，无需任何路径改写。

## 注意事项

- 本应用通过飞牛应用中心接口动态管理桌面快捷方式，属于较底层的操作，**请仅在受信任的内网环境使用**
- 反向代理对象请确保是**你自己有权访问的内网服务**，不要用于绕过访问控制
- 已内置安全头剥离（X-Frame-Options、CSP frame-ancestors、HSTS 等）以保证站点能在小窗内正常打开
